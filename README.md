# DAI (Decentralized AI)
This repository supports a systematic literature review and knowledge synthesis on Decentralized Artificial Intelligence (DAI) systems. It provides tools, data, and documentation to conduct a systematic literature review and synthesize current knowledge in the field.

The review addresses DAI's architectural, technological, and governance foundations, identifies key application domains, and highlights open challenges and research opportunities.

Research Objectives
This project is organized to answer the following Research Questions (RQs):
- RQ1: What are architectural patterns and core technologies enabling Decentralized AI?

- RQ2: How are blockchain and smart contracts used to coordinate and govern these systems?

- RQ3: What are the primary application domains and benefits of DAI systems?

- RQ4: What are the open challenges, limitations, and opportunities for future research?
