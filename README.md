# DAI (Decentralized AI)
This repository supports a systematic literature review and knowledge synthesis on Decentralized Artificial Intelligence (DAI) systems. The project investigates the current state of DAI, focusing on its architectural patterns, enabling technologies, governance mechanisms, and emerging application domains.

The repository includes:
-A curated list of relevant academic papers
-Scripts and tools for extracting and managing publication data from online sources
-Project materials and analysis workflows organized to address key research questions

Research Objectives
This project addresses the following Research Questions (RQs):
-RQ1: What are architectural patterns and core technologies enabling Decentralized AI?
-RQ2: How are blockchain and smart contracts used to coordinate and govern these systems?
-RQ3: What are the primary application domains and benefits of DAI systems?
-RQ4: What are the open challenges, limitations, and opportunities for future research?
